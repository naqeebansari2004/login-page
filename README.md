# 🔐 University Login Page

This project is a responsive and visually appealing login page designed as part of my university training during the second year of my Bachelor of Computer Applications (BCA). It showcases fundamental web development skills using HTML and CSS.

## 🖼️ Preview
![image](https://github.com/user-attachments/assets/4a67f770-36da-4fc2-bd8d-f3c1905487c8)


## 📄 Features

- **Responsive Design**: Ensures compatibility across various devices and screen sizes.
- **University Branding**: Incorporates the university's logo and color scheme for a professional appearance.
- **User-Friendly Interface**: Simple and intuitive layout for easy navigation.

## 🧱 Tech Stack

- **HTML5**: Structuring the login page elements.
- **CSS3**: Styling and layout design to enhance visual appeal.

## 📁 Project Structure

```
login-page/
├── index.html         # Main HTML file
├── style.css          # CSS styling
├── united.jpeg        # University logo or related image
├── United_logo.webp   # Additional branding image
└── README.md          # Project documentation
```

## 🚀 Getting Started

To view the login page locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/naqeebansari2004/login-page.git
   ```
2. Navigate to the project directory:
   ```bash
   cd login-page
   ```
3. Open `index.html` in your preferred web browser.
